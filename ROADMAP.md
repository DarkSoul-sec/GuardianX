# 🛡 GuardianX Roadmap

This roadmap shows where the project is heading. It is a directional guide, not a
set of commitments — as with most security platforms, scope and priorities evolve
as the ecosystem and user feedback change.

---

## ✅ v1.0 Beta

Current feature set. Work is focused on Release Candidate polish: stability,
authentication, UI/UX, installation, and documentation.

- Asset Management
- Network Discovery
- Nmap Scan Engine
- Attack Surface Management
- CVE Enrichment & Risk Scoring
- Findings Triage & Bulk Actions
- Threat Intelligence
- Vulnerability Intelligence
- VirusTotal (Bring-Your-Own-Key) Integration
- Phishing Detection Analysis
- SOC: Alerts, Incidents, Activity History
- AI Copilot (OpenAI / Gemini / Ollama / rules)
- Guardian Agent
- Executive Reports
- Role-Based Access Control
- JWT Authentication & Session Management
- Notifications and Activity Log

---

## 🚧 v1.5

Development / next round of improvements.

- Performance Improvements
- Better Reports
- UI Enhancements
- Scan Engine Optimization
- Expanded Intelligence Sources

---

## 🔮 v2.0

Planned, direction only — eager to refine with community input.

- Enterprise Multi-Tenant
- Incident Response
- Plugin SDK
- Extended Integrations
- Advanced Automation & Policy Engine
